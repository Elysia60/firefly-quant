> 侦察日期:2026-11-13 · 已落地:audit.py(NW/bootstrap/事件研究)+ metamdl.py(13 测) · [S4] 注册即本报告的实证产出

## 一、DSR 参考实现(交叉对拍用,四个口径陷阱)

1. **rubenbriones/Probabilistic-Sharpe-Ratio**(Python,最流行社区参考):SR 标准误分母 (T−1);峰度 **Pearson 口径(fisher=False,正态=3)**;试验数折减 N_eff = ρ+(1−ρ)·M 向上取整;Gumbel 极值近似 E[max SR]。
2. **mnemox-ai/deflated-sharpe**(纯标准库,Apache-2.0):与萤火零依赖路线同构;附 min_backtest_length 二分搜索 + Benjamini-Hochberg FDR;**不做相关性折减**(与 1 互补,正好对拍两档)。
3. **esvhd/pypbo**(AGPL-3.0,**只对拍数值不复制代码**):PBO/CSCV+PSR+MinTRL+DSR 一站式。
4. mlfinlab 2021-22 起闭源收费,勿依赖;官方书代码 mlopezdeprado/Advances-in-Financial-Machine-Learning。

**核心公式**(标准库自研 4 件):
```
σ(SR̂) = sqrt[(1 − γ₃·SR̂ + ((γ₄−1)/4)·SR̂²)/(T−1)]     γ₄=Pearson 峰度(正态=3)
PSR(SR*) = Φ[(SR̂−SR*)·√(T−1)/σ(SR̂)]
SR₀ = E[SR] + σ_trials·[(1−γe)·Φ⁻¹(1−1/N) + γe·Φ⁻¹(1−1/(N·e))]   γe=0.5772
DSR = PSR(SR₀) > 0.95
```
**对拍清单**:①峰度口径(最易错) ②分母 T−1 vs T ③N 折减两档 ④**T 必须有效化**——重叠前向收益直接喂=DSR 虚高;干净解法=改用持仓展开日度 PnL(非重叠)。

## 二、重叠样本显著性检验(n_eff//n 之外的升级)

- **方案 A(推荐主力):Newey-West HAC t**,L=max(n−1, ⌊4(T/100)^{2/9}⌋):
  `Var(x̄)=(1/T)[γ̂₀+2Σ_{l=1..L}(1−l/(L+1))γ̂_l]`(Bartlett 权重)——已落地 audit.py
- **方案 B:Stationary Bootstrap**(Politis-Romano 1994):p=1/b 延续概率 1−p 越界回绕;**块长 b ≥ 重叠窗径 n**;CI 百分位法——已落地
- 方案 C:AR(1) ESS 一行修正(T_eff = T(1−ρ)/(1+ρ))——介于两者之间
- 了解即可:Hansen-Hodrick(无 Bartlett,小样本偏)、Britten-Jones 转换回归、Hjalmarsson(Fed IFDP 853)
- 参考:bashtage/arch(bootstrap/SPA 口径基准)、Stata FAQ 重叠收益、quantmemo NW 讲解

## 三、事件研究对照设计(已落地 audit.event_study)

随机化推断 + 匹配对照(World Bank RI / Miller JEP 2023 / Coglianese Fed placebo):
```
for e in E: C_e = 同条件对照日, |j−e| > n 防污染
d_obs = mean(y_E) − mean(y_C)
置换 p = (1+#{d_b ≥ d_obs})/(B+1)   # 池化重排标签
```
- Abadie 三件套:**in-time placebo 适用**(前置窗 CAR 应不显著);placebo-in-space 不适用(无截面 donor);坏对照按前置特征分层修剪
- 信号聚集时个体 iid 失效 → 块长≥聚集长度的 stationary bootstrap
- Kolari-Pynnönen 截面相关修正(了解)

## 四、White RC / Hansen SPA(有全时间序列后启用)

- **bashtage/arch** 唯一维护良好实现:`SPA(benchmark, models, block_size≥重叠窗径)` 三 p 值(lower/consistent/upper)
- 自研公式:`T_n^SPA = max[max_k √n·d̄_k/ω̂_k, 0]`,重中心化 LIL 阈值 `√(2 ln ln n)`
- **DSR vs SPA 边界**:DSR 只需汇总指标(被选者推断);SPA 需逐试验时间序列(家族关)——互补不互替,先 SPA 过家族关再 DSR

## 五、Meta-labeling(本报告核心,[S2] 的解法)

### 样本构造(AFML Ch.3)
- **事件驱动采样:只有主信号触发日进训练**(非触发日没有赌注)
- Triple-barrier:横挡 = side×h·σ(h=1.0~1.5),竖挡 1~5 日;先触同向挡 y=1,否则 0;标注路径结果非次日涨跌
- 类不平衡:上采样 / AFML 唯一性权重
- **必须 purged K-fold+embargo**(屏障路径重叠会泄漏;H&T 实证:验证精度 37%→56%)

### 特征与模型
- H&T 清单:15/31/50 bar 滚动波动、1-5 日自相关、1-5 日动量;或 RSI+波动+均线
- **Joubert 2022(JFDS):概率校准(Platt/isotonic)比换模型更重要**
- 模型 RF/逻辑回归即可;纯标准库 IRLS ~30 行

### 概率→仓位(AFML Ch.10)
```
z = (p − 1/K)/√(p(1−p))    K=2
m = clip(2z − 1, 0, 1)
仓位 = side × m,按 stepSize=0.05 分桶;并发信号取加权均值
```
萤火最短路径可跳过 z 变换,直接用校准后 p 的分位桶。

## 六、HAR-RV 与日线波动率估计器(TSFM 实验的公平基线)

- **HAR(Corsi 2009)**:`RV_{t+1} = β0+βd·RV_d+βw·RV_w+βm·RV_m`,对 **log(RV)** 回归 + NW HAC;`rv_w=rolling(5).mean(), rv_m=rolling(22).mean()`
- 无分钟数据的 RV:**Yang-Zhang(2000) 唯一同时处理隔夜跳空与漂移**(效率 14×,MIT 案例误差最小):`σ²_YZ = σ²_隔夜 + k·σ²_开收 + (1−k)·σ²_RS,k=0.34/(1.34+(T+1)/(T−1))`;**A 股涨跌停日 H/L 截断低估 → 标记**
- EWMA(λ=0.94)闭式兜底;GARCH MLE 成本>收益不借
- TSFM 实验评估纪律:QLIKE 主(对 RV 代理噪声稳健)+ Diebold-Mariano + Mincer-Zarnowitz(α=0,β=1);基线 = "TTM 等权+Log-HAR"(Brini arXiv 2607.05291:进 98-100% 资产的 MCS)
- BIS WP(Shi 2026 Beyond the HAR):HAR 非天花板,但复杂模型性价比低

## 七、信号融合(与 meta-labeling 一步合并)

- 2~5 个信号:**简单平均是最稳健基线**(Bates-Granger 1969,50 年综述再确认)——V0
- 逆方差/逆回撤加权:3~10 个信号
- 堆叠回归:≥5 个信号才稳(2-3 个时 OOS 权重不稳=二次过拟合,不借)
- **regime 当 meta 特征喂二级模型 = 融合与 meta-labeling 同一架构**,不另起炉灶
- 多重检验:Bonferroni(已有)+ BH FDR(筛特征)+ RC/SPA(最优变体)+ Harvey-Liu-Zhu(t≥3)
- **最关键纪律:"融合方案"本身也是试验,每次 N+1 计入 DSR;V1 只许固定一套配置**
