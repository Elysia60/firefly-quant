### P3 · regime 门控(第 6 周周期引擎,[S1] 的最终审判)——调研定案(2026-11-13)

**侦察结论:规则法是唯一天然因果的一类;HMM 必须滚动 refit+手写前向滤波(平滑后验≠滤波概率,是最常见隐蔽泄漏)。**

门控三特征(全部事前可算、O(n)、只用 ≤T-1):
1. **年线滞回**(主信号):MA250,进多区 ×1.01 / 退多区 ×0.96——A 股实测参数(davidwang0116 回测,比美股 1.03/0.83 窄,A 股牛熊转换更陡);可选年线斜率确认
2. **年线宽度** breadth250:站上 MA250 个股占比 >0.6 多头 / <0.4 空头(湖内可算,零依赖)
3. **波动否决** vol_veto:20 日已实现波动率 500 日分位 >0.9 → 否决加仓类信号

合成算法:**三票二 + 5 日持续确认去抖**(bear=年线下+宽度缩+波动极端,≥2 票);三态(含 neutral)——neutral 不覆盖信号,bear 才否决(与 [S1] 兼容:门控在修复年的作用是缩短而非替代)
- 借:davidwang0116 滞回参数、ItsSawhill walk-forward 骨架(3年窗/每月refit/冻结参数)、hmmlearn 引擎+手写前向递推(勿用 predict_proba)
- 不借:全样本 Viterbi/后验、KMeans+宏观堆叠、BOCPD 当主列、估值分位/信用脉冲当**日度**门控(只能做月度慢过滤)
- [S1]-反方观测 ②:事前门控分层后 d_obs 不显著 → 撤销条件结论

### P5 · 未来两层预研定案(ML 选股层 + AI 研究管线层)

**ML 选股层(2-4 周量级,全部走自家审计):**
1. Alpha158 按"5 类(K线/动量/波动/极值/量价)× 4 窗口(5/10/20/60)"收敛 ~40 个因子,湖内纯 pandas 实现
2. 首批外源因子 10 个:**华泰实证筛出的 Alpha#3/13/15/16/44/50/55**(A 股 101 因子全量回测幸存者)+ 3-5 个 Alpha191 纯价量因子(先与聚宽 alpha191.py 对拍——WMA/DECAYLINEAR 开源复现错误率极高)
3. LightGBM + 横截面 Rank IC 目标;上线前专审复权口径 PIT(因子公式无 PIT,风险全在数据处理)
4. 组合层零依赖改造:TopK → **行业分层 TopK**(东方证券/光大研报背书:分层拿到优化器大部分超额)→ 逆波动率加权 + 单票 35% 上限 → 指数 vol targeting。不用 cvxpy

**AI 研究管线层(ML 基线后,1-2 周):**
5. **不自建 agent 框架,把审计做成 agent 工具**:数据湖查询/因子 IC/记分牌/回测包成 MCP 工具(DSH 体系现成),LLM 提因子假设→写 pandas 实现→记分牌打分→回填迭代(RD-Agent 循环,验收信号换成事件研究级审计)
6. 抄 AlphaAgent 两条正则:AST 原创性(拒重复因子)+ 表达式复杂度上限(防过拟合),~100 行
7. 成本现实:RD-Agent(Q) 参考 <$10/周期(o3-mini),DeepSeek 后端 1-2 美元;**瓶颈不在算力在审计严格度——萤火的主场**;半自动(agent 提案+人过审)是个人开发者正确形态
8. 差异化空位:全开源(RD-Agent/AlphaAgent/Alphagen)都没有"审计进反馈回路"——**对账记分牌 MCP 化就是别人没有的东西**
