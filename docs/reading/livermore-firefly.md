## 2. 交易体系五条(趋势交易的完整语法)

### ① 关键点(Pivotal Points)
只在关键点入场——箱体突破/最小阻力线确认,**等市场证明你是对的再动**。
→ 萤火对应:触发面板的"状态确认"思想;[S10] 的 30 天提前量本质是"等形态出现,
不猜日期"。利弗莫尔 1915 年伯利恒钢铁翻身仗:等了六周才在关键点出手——
**等待本身就是仓位**。

### ② 趋势与最小阻力
市场沿最小阻力方向运行,不逆势。判断错了不是"看法错了",是"仓位站错了边"。
→ 萤火对应:regime 门控(年线滞回 1.01/0.96)=趋势确认器的制度化;[S16] 门控
保险的赔付条款。

### ③ 金字塔加仓(Pyramiding)
首仓试探(1/4),**浮盈证明方向正确后才加仓**,越加越少(正金字塔);
**绝不在亏损仓位上摊平**。
→ 萤火对应:roadmap P6 仓位管理——试仓+金字塔是"仓位三选"之外的第四选项设计;
与 [S15] 互证:加仓也是交易,也要过边际成本检验(曼昆③)。

### ④ 止损
快速认错;**止损单下给券商,不下给自己**(心理止损在恐慌时必然失灵);
单笔亏损通常 ≤ 总资金 10%。
→ 萤火对应:**P6 回撤熔断至今"待实装"——利弗莫尔给出经典参数**:单笔 -10%
强制离场、组合回撤阈值→自动降仓档位。这是本轮补强的直接落点。

### ⑤ 坐稳(Sitting Tight)
原话:"**大钱从来不是我的思考赚来的,是我的坐着**。"(It never was my thinking
that made the big money, it was always my sitting.)
→ 萤火对应:[S2](日频开关全灭)、[S15](换手守恒)、[S16](门控保险)——三条
结论合起来就是"坐着"的量化版:少动、让趋势自己走、用规则而不是情绪决定何时
不坐。**1929 年他在崩盘中赚 $1 亿靠的是做空后的"坐",不是频繁操作。**

### 附加两条
- "华尔街没有新东西"——与曼昆/特维德同源:周期重复,人性不变。
- 不听消息(1908 棉花之败=听信专家)→ 萤火数据纪律:只用可对账的数据,
  不用"据说"。

## 3. 反推:利弗莫尔的一生 = 一台没有守卫层的萤火

这是本次精读最深的一层,直接回答"萤火为什么存在":

**他的规则全部正确**——止损、关键点、坐稳、金字塔,1940 年书里写下的每一条
至今仍是趋势交易的正典。**但他本人三次破产、孤独自杀。**为什么?

1. **规则在脑子里,不是在机器里**——抑郁症、婚变、深夜孤独时,人是守不住自己
   的规则的。1940 年的他知道全部正确答案,依然扣下扳机。
2. **没有制度化风控**——他的仓位是他的勇气,不是规则的输出。三次破产都是
   "全仓+杠杆+个人判断"的同一结构反复重演。
3. **规则环境变了没适配**——1934 年 SEC 成立、报价与交易结构剧变,旧规则的
   参数失效(类比萤火 [S16] 的"门控参数有效期"与规则变更事件表)。

**推论(理念层终审)**:个人交易者的终极风险不是"没有规则",是**有了规则守不住**。
所以规则必须机器化:守卫层(fail-closed)、注册表(结论可对账)、半自动(提案+
人过审)、看门狗(体检+演练)——萤火的每一层工程,都是在回答同一个问题:
**"如何保证 1940 年的利弗莫尔悲剧不会以你的名字重演?"**

知识 ≠ 制度。他的书救不了他,但可以救你——前提是把书变成机器。

## 4. 补强行动项(萤火)

1. **P6 回撤熔断公式级参数**(本轮直接落 roadmap):利弗莫尔 10% 规则 →
   单笔 -10% 强制离场 / 组合回撤 -15%→降仓至半 / -25%→清仓待重启(预注册,
   DSR 中性——纯风控参数,不产生信号)。
2. **关键点仪表候选**:箱体突破确认(20 日箱体上沿+量能)入触发面板候选池,
   预注册观察,不进决策。
3. **试仓-金字塔**:P6 仓位第四选项(probe 1/4→浮盈加仓),写进 P6 设计备选。
4. **"坐"的工程化**:利弗莫尔规则的机器版已经存在——[S2]/[S15]/[S16] 三条
